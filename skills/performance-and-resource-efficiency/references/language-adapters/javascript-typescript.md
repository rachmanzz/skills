# JavaScript and TypeScript Adapter

Check allocation churn, object shape stability, array materialization, promise
fan-out, event-loop blocking, and garbage-collection behavior. Avoid creating
large intermediate arrays when a bounded iterator or stream is sufficient.

Bound asynchronous concurrency and set deadlines for database, network, and
cache clients. Treat `lru-cache` as one possible local implementation, not as a
replacement for shared backends or database fallback.
